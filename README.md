# لینک‌یار — ربات تلگرام فایل → لینک دانلود

فایل را در تلگرام بفرست؛ ربات آن را روی همین سرویس ذخیره می‌کند و یک لینک دانلود مستقیم برمی‌گرداند.

## چطور کار می‌کند؟

```
تو ──فایل──▶ تلگرام ──▶ این ربات ──ذخیره──▶ دیسک سرور
                              │
                              └── لینک http://سرور/d/xxxxx ──▶ هر کسی دانلود کند
```

1. توکن ربات را از `@BotFather` می‌گیری.
2. این برنامه را روی **یک سرور همیشه روشن** اجرا می‌کنی (VPS ارزان، همین ماشین، یا هر لینوکسی).
3. `PUBLIC_BASE_URL` باید همان آدرس عمومی آن سرور باشد تا لینک‌ها از بیرون باز شوند.
4. فایل را به ربات می‌فرستی → لینک `/d/...` می‌گیری.

### آیا به هاست DirectAdmin نیاز داری؟

**نه به‌صورت خاص.** DirectAdmin فقط یک پنل مدیریت هاست است. این پروژه خودش فایل را نگه می‌دارد و لینک می‌دهد.

چیزی که لازم داری:

| لازم است؟ | توضیح |
|-----------|--------|
| سرور / VPS همیشه روشن | بله — ربات و فایل‌ها باید جایی اجرا/ذخیره شوند |
| توکن `@BotFather` | بله — برای وصل شدن به تلگرام |
| دامنه + HTTPS (اختیاری ولی بهتر) | برای لینک تمیز و مطمئن |
| هاست DirectAdmin جدا | خیر |

اگر فقط روی لپ‌تاپ لوکال اجرا کنی، لینک فقط وقتی کار می‌کند که سیستم روشن باشد و آدرسش از اینترنت قابل دسترس باشد (مثلاً با تونل مثل Cloudflare Tunnel / ngrok).

## محدودیت تلگرام

Bot API معمولاً تا حدود **۲۰ مگابایت** برای دانلود فایل از تلگرام محدودیت دارد. برای فایل‌های خیلی بزرگ باید یا از روش دیگری آپلود کنی (فرم وب همین سرویس) یا Bot API لوکال راه بیندازی.

## اجرا

```bash
cp .env.example .env
# TELEGRAM_BOT_TOKEN و PUBLIC_BASE_URL را پر کن
npm install
npm run dev
```

باز کردن پنل وضعیت و آپلود آزمایشی:

- http://127.0.0.1:38471

بدون توکن هم سرور وب بالا می‌آید تا آپلود/دانلود را تست کنی؛ فقط ربات تلگرام خاموش می‌ماند.

### متغیرهای مهم `.env`

- `TELEGRAM_BOT_TOKEN` — توکن ربات
- `PUBLIC_BASE_URL` — آدرس عمومی، مثلاً `https://dl.example.com`
- `PORT` — پیش‌فرض `38471`
- `ALLOWED_USER_IDS` — اختیاری؛ فقط این یوزرآیدی‌ها اجازه آپلود دارند
- `MAX_FILE_BYTES` — سقف حجم

یوزرآیدی خودت را با دستور `/id` داخل ربات ببین.

## دستورهای ربات

- `/start` — راهنما
- `/id` — یوزرآیدی
- `/ping` — وضعیت
- ارسال سند / عکس / ویدیو / صوت — ساخت لینک

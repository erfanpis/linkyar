# Linkyar

ربات تلگرام خصوصی ساخت لینک دانلود.

## حالت اجرا

۲۴ساعته با long-polling فوری روی GitHub Actions.
هر جاب حدود ۵ ساعت زنده است و در پایان خودش جاب بعدی را روشن می‌کند.

## Secrets

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `RESPAWN_PAT` (توکن با مجوز workflow برای روشن‌کردن خودکار جاب بعدی)

مدیر: `ADMIN_USER_IDS`

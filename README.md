# Linkyar

ربات تلگرام خصوصی برای ساخت لینک دانلود مستقیم از فایل.

## امکانات

- تأیید قبل از ساخت لینک
- نمایش پیشرفت هنگام آماده‌سازی
- دسترسی فقط با تأیید مدیر
- انقضای خودکار لینک بعد از ۶ ساعت
- پشتیبانی فایل‌های بزرگ (تا ۲ گیگ با MTProto)

## اجرا

ربات روی GitHub Actions با جاب‌های چندساعته تقریباً ۲۴ساعته می‌ماند
(هر جاب حدود ۵ ساعت تلگرام را مدام چک می‌کند).

```bash
cp .env.example .env
npm install
npm run poll
```

Secrets:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`

مدیر: `ADMIN_USER_IDS`
